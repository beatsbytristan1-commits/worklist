Connect to your data

Your lists live in the private GitHub repository beatsbytristan1-commits/worklist-data. Paste a personal access token that can write to it and this device is set up for good.

  1. Open github.com/settings/personal-access-tokens
  2. Repository access → Only select repositories → worklist-data
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate, copy, and paste it below

The token is stored only in this browser and is sent straight to github.com — nowhere else.
